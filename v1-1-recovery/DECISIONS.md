# v1.2.3 적용 결정

1. 상단 구조부터 변경: 긴 노란 식단 바를 제거하고 10가지 식이 유형의 SVG 아이콘 버튼을 다른 상단 버튼과 함께 배치했습니다. 로고와 노란 바 사이 간격 수정은 불필요해졌으며, 작고 연결된 청록색 돋보기로 로고를 다듬었습니다.
2. 글자 크기와 카드 배치 연결: 기본 2단계는 3열, 3단계는 2열, 4단계는 1열입니다. 사용 가능한 카드 영역이 좁으면 열 수를 추가로 줄입니다. 기존 글자 크기를 유지하며 이름과 설명은 줄바꿈합니다.
3. 모달 공통 구조 정리: 레시피 제목을 전체 폭의 별도 행에 배치하고 줄바꿈합니다. 설정 저장 버튼의 고정 영역 배경을 투명하게 바꿨습니다.
4. 식탁 카드 정보 정리: 판정 → Meal 선택 → 수량 → 삭제 순서로 조작부를 배치했습니다. 칼로리와 묶인 탄수화물·단백질·지방은 아래에 표시합니다.
5. 인식 확인 흐름: 여러 인식 재료를 선택·수량 조정한 뒤 한 번에 확인합니다. 담기가 끝나면 모달을 모두 닫습니다. 낮은 신뢰도 항목은 직접 선택해야 담깁니다.
6. 오른쪽 위젯 마감: 밝은 반투명 민트색 배경, 읽을 수 있는 청록색 문자와 테두리를 사용합니다. 스크롤바를 제외한 화면 폭으로 위치를 계산합니다.

v1.2.2의 식재료 초기 접힘, 짧은 접기 버튼, 네 단계 글자 설정, 식탁 전체 비우기 및 기존 데이터 보존을 유지했습니다.
